# QA Testing Portfolio

Manual testing work by **Md. Rahat Pervez**: test case design from a product requirements document (PRD), and hands-on bug testing of a live web application.

## Projects

| Project | What it is | Highlights |
|---|---|---|
| [QuickBite: Test Case Design](quickbite-test-case-design) | Test cases written from the PRD of a food ordering and delivery app | 74 test cases across 9 modules, 71 traced to requirement IDs, 4 PRD ambiguities flagged |
| [Sweet Shop: Bug Report](sweetshop-bug-report) | Functional and exploratory testing of a live web app, written up as a bug report | 22 issues logged, 12 confirmed bugs (2 critical), root causes traced in Chrome DevTools |

The login automation (Selenium with Python) is in its own repository: [automationexercise-login-test](https://github.com/rahatpervez/automationexercise-login-test)

## Skills shown

- Requirement analysis and static review of a PRD
- Test case design: functional, boundary, negative, edge and non-functional cases
- Requirement traceability
- Bug reporting with severity, steps to reproduce and screenshots
- Chrome DevTools (Console, Network and Elements tabs)

## Context

Both projects were completed in September 2026 as a take-home assessment for an SQA Engineer Intern role.
